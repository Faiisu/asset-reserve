🔎 Asset Recognition — Demo

This page is only a demo harness for the actual deliverable: the recognition API itself (POST /api/assets, POST /api/recognize, POST /api/recognize/multi). It exercises the same HTTP endpoints your main app's backend would call. Left = manager registering an asset when it's lent out. Right = a borrower photographing the asset(s) on the table when returning them.

ℹ️ Real flow: manager uploads asset photo once (register) → borrowing happens in your main app → on return, borrower snaps a photo → this API tells you which asset it is and how confident it is.
